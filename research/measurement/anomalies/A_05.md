# Baseline Comparison

- **Vs homog_short (best-case):** mixed is 27% slower thr and 34% higher p50 — expected because average service time higher (mixed avg output 144 vs short 32, input 576 vs 128).
- **Vs homog_long (worst-case):** mixed is 70% faster thr and 54% lower p50 — mixed improves over worst-case by reducing average load (mixed avg input 576 vs long 1024, avg output 144 vs 256).
- **Isolation expectation (literature SGLang):** expected greedy cache-aware scheduling to cause starvation / tail hotspot for cold class (see paper_notes/SGLang.md:200). Here naive FIFO with no cache shows opposite: long benefits from mixing, short not harmed — suggests isolation failure is implementation-specific (needs prefix cache + affinity), not present in naive system.
- **Load-only parity:** if service time were additive, mixed thr should be harmonic mean of short and long thr (1/(0.5/1.139+0.5/0.485)=0.68) vs observed 0.826 (+21% higher) — indicates concurrency benefit.

# Reality Check

- **Realistic:** YES. Mixed short/long is realistic for RAG (short chat + long document) or agent (tool calls varied). Conc4–8 realistic. 1:1 ratio is plausible but synthetic. Real traffic would have more short than long.
- **Plausible:** Long benefit from mixing is plausible due to lower average load (mixed avg tokens less than pure long), not due to scheduling.
- **Stress-test:** 50% long is maybe high for real (more stress than typical chat), but still plausible for RAG heavy.
- **Synthetic-only risk:** Moderate — prompt templates are filler, not real documents; service time difference is due to output length (32 vs 256) which is real, but input length difference (128 vs 1024) is truncated? No, 1024 within limit, so not truncated. Effect is driven by output.

# Preliminary Importance

**Medium**

- Quantifies that on naive system, mixing does not create isolation failure for short; instead long improves — a useful negative result for RQ-4 (affinity vs tail) which predicted hot-class hotspot.
- Shows that average load, not scheduling, dominates here — for Stage 3R-C, any claim about cache-affinity induced tail must control for average token load, otherwise mixed benefit will be misattributed.
- Effect size is large (70% thr, 31–38% long latency) and directionally surprising (opposite of expected harm), but cause is simple (load averaging) not a new bottleneck.
