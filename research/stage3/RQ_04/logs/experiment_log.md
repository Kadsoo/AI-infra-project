## 4. Development fixes (all before the final runs; final hashes above)

1. E0: Abate-Whitt Euler inversion - half-weight on the k=0 trapezoid term and
   the e^{A/2}/t scaling (validated against exact M/M/1 quantiles to 3.6e-9).
2. E0: unit consistency - lambda_sat, per-node rho, service moments and the
   service LST now carry gamma*GAMMA_BASE consistently (the transform pair
   lam, S~ must satisfy lam*E[S] = rho; the first version was 2048x off, which
   corrupted the P99 quantiles while leaving mean waits intact).
3. E0: load-only node arrival rate is the per-node rate lam/4 (cluster rate
   was passed to the inversion); overload cells (rho_hot_full >= 1.0) return
   NaN for M/G/1 predictions and are excluded from verdicts.
4. E1: per-request records carry wait/svc_tokens/cached; hit rate uses
   cached/(cached+uncached); admission dispatch uses the admission time; node
   queues are deques; leaf accounting uses svc_tokens; duplicate run_ids are
   replaced in place (never drop a run).
5. E1: deterministic warm-up realization (A: warm-up hot requests -> node 0)
   - without it the hot prefix spread to all 4 nodes during warm-up and A
   degenerated to B (identical outputs).
6. E1: uniform-random tie-break among exact minima (seeded per run) for
   policies B/B' and A's cold ties - deterministic index tie-breaks biased
   node 0 to ~2x the balanced load (rho_0 = lambda*E[S]/(1+lambda*E[S])),
   contradicting E0's balanced baseline.
7. E1 report: ratio columns used pandas index alignment (NaN); fixed with
   .values (rerun at 15:21Z).
